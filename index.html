Connecter un téléphone

Scannez ce code avec l'appareil photo du téléphone : RSG s'ouvre déjà relié à votre base. Connectez-vous ensuite avec le même e-mail et le même mot de passe.

Sur le téléphone, ajoutez ensuite RSG à l'écran d'accueil : dans Chrome, ⋮ → Ajouter à l'écran d'accueil.
